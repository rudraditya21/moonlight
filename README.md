# Moonlight

Moonlight is a modular security framework engineered for offensive security research and red team operations.

## Setup

```
git clone https://github.com/rudraditya21/moonlight
cd moonlight
```

Install a stable Rust toolchain.

## Build

```
make build
```

## Run

```
make run
```

## Test

```
make test
```

## Format

```
make fmt
```

## Lint

```
make clippy
```
